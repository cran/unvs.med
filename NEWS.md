# unvs.med 1.1.0
New version released.

## New features
Users can specify an arbitrary value of the exposure level when estimating mediation effects, 
i.e., the baseline level and the new level of the exposure, respectively.
It can be realized by simply adding parameters "exp0" and "exp1" in the main function 'FormalEstmed'.
